## 已实现的行为

- 成功提交前在控制临界区再次核查当前合同、可信文件、源码输入指纹和产物摘要。原核查之后变化的文件阻止成功；无法核查的文件进入可恢复 blocked。
- 通过 TaskBlockedError 的类型和代码识别未确认效果。目标文件缺失、访问失败、回执查询抛出错误不再误判为不可恢复 failed；不补交虚构的工具结果、不重放副作用，宿主恢复条件后显式 resume。
- 保留查询失败的诊断，由现有脱敏器写入状态；必要日志提交失败仍停止执行，不能被包装为已确认的恢复结果。

没有增加依赖、任务格式或调度层。成功绑定提交前最后一次核查的文件版本；执行权只约束协作执行者，不阻止其他主机进程随后修改工作区。
